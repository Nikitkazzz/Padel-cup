# Alif × Idea Padel Cup: сайт турнира на Netlify

Что внутри:
- `public/index.html` — сама страница турнира;
- `netlify/functions/state.mjs` — серверная функция, которая хранит результаты в Netlify Blobs и пускает к записи только по PIN организатора;
- `netlify/functions/seed.mjs` — стартовые данные: тур 1, пары, регламент. Используются до первого сохранения;
- `netlify.toml`, `package.json` — настройки сборки.

## Запуск (около 10 минут)

1. **GitHub.** Создайте новый репозиторий (можно приватный). На пустой странице репозитория нажмите «uploading an existing file», перетащите в окно всё содержимое этой папки (папки `public` и `netlify`, файлы `netlify.toml`, `package.json`, `README.md`) и нажмите «Commit changes».
2. **Netlify.** Add new project → Import an existing project → GitHub → выберите репозиторий. Настройки сборки подтянутся сами из `netlify.toml`, ничего менять не нужно. Нажмите Deploy.
3. **PIN организатора.** Project configuration → Environment variables → Add a variable: ключ `ORGANIZER_PIN`, значение — PIN не короче 8 символов. Затем Deploys → Trigger deploy → Deploy project, чтобы PIN применился.
4. **Проверка.** Откройте адрес сайта → вкладка «Туры и пары» → «Режим организатора» → введите PIN. Матчи станут кликабельными.

Участники открывают ту же ссылку без входа и видят результаты. Страница обновляется сама раз в 10 секунд.

## Правки

Любое изменение файлов в репозитории GitHub автоматически публикуется на сайте за минуту. Данные турнира (счёт, пары, регламент) при этом не стираются: они хранятся отдельно, в Netlify Blobs.
